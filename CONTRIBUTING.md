# Contributing

This repository is primarily a portfolio and case-study record. There may not
be an active contributor community, but careful feedback and small
documentation corrections are welcome.

## Ways to share feedback

If GitHub Issues are enabled, open an issue to:

- Report a documentation problem or identify an accessibility concern.
- Suggest a research question or propose a correction.
- Explain the evidence or context behind a suggested change.

You can also submit a small documentation pull request. Keep changes focused,
cite sources where possible, and distinguish verified evidence from a
proposal. Please do not add unreviewed application code or present proposed
behavior as implemented.

## Issue template

Use the following headings when opening an issue:

### Problem or observation

What did you notice?

### Context

Where does it occur, and who or what may be affected? Do not include
identifying or sensitive personal details.

### Expected behavior or improvement

What would be clearer, more usable, or more accurate?

### Evidence

Link to relevant documentation, code, or other non-sensitive evidence.

### Accessibility considerations

Which access needs or interaction contexts should be considered?

### Proposed next step

What focused action could address the concern?

### Validation needed

What review, testing, or participatory input would be needed?

## Privacy and safety

Do not submit confidential case information, private participant data, or
sensitive personal disclosures. Describe concerns without identifying people
or exposing private legal or health information.
